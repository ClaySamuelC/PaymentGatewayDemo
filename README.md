# Payment Gateway Demo
The purpose of this application is to provide a demo which functions as a payment gateway similar to PayPal.
- It should provide 3DS, and PCI DSS compliance
- It should allow for multiple payment types (Visa, mastercard, etc...)
- It should allow for providing payment information as input and demonstrate working test transactions on them (use dummy cards as input).
- It should demonstrate proper security standards (Encryption, SSL)
- It should not store card information
- It should be highly available
- It should demonstrate proper logging while maintaining privacy
